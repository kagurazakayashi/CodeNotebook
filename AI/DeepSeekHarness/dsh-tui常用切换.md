# dsh-tui 常用切换

## 只读 / 工作区读写 / 完全访问：
输入 `/permission` 打开选择器
也可以直接输入 `/permission read-only`  `/permission workspace-write`  `/permission danger-full-access`

## Agent 预设（standard / code / minimal / cordis / liangshen）：
用 `/preset`。
也可以直接输入 `/preset standard` ...

## 换模型：
`/model`
也可以直接输入 `/model deepseek/deepseek-v4-flash` ...

## 思考模式（high / max）：
`/effort`
`/effort off`  `/effort high`  `/effort max`
