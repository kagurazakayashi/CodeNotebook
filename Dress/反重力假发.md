# 反重力假发制作备忘录

> 面向 cosplay / 毛娘场景的"反重力"（gravity-defying）造型假发制作笔记。
> 涵盖：材料准备、金属丝弯折与配置、不织布选择与安装、假发本体处理（剪/贴/缝/倒梳）、常见发型实施步骤。
> 文中线径、厚度、幅宽等数值为社区经验参考值，实际以手感与造型大小调整。

---

## 0. 核心原则（先看这段）

反重力造型 = **内骨架撑形** + **外层包裹（给发丝附着面）** + **发丝铺覆 + 定型固化**。
三明治结构：`金属丝骨架 → (填充棉) → 不织布外壳 → 发帘/散发 → 发胶定型`。

四条决定成败的铁律：

1. **根部锚定 > 一切**。大造型的全部重量与杠杆力（弯矩）都压在根部，根部没固定好，整束会塌、会扯破底网。先解决"怎么稳稳挂到头上"，再做造型。
2. **控制重量与重心**。越重、越往外伸，根部弯矩越大、整顶越容易后坠/滑脱。能轻则轻（铝丝、空心、少填充）、重心尽量贴近头部。
3. **对称靠模板**。成对造型（双马尾、双尖角）先做纸样/先定一侧，再照抄另一侧。
4. **所有金属端头必须收圈或包覆**。防扎头皮、防戳破不织布与发丝。

## 1. 材料与工具清单

### 1.1 骨架（金属丝）
| 材料 | 评价 | 说明 |
|---|---|---|
| **铝丝（armature / 铝合金丝）** | ★首选 | 轻、不生锈、易弯、断口不太尖；缺点是回弹略大、太细撑不住 |
| 镀锌铁丝 / 退火铁丝 | 可用 | 重、会金属疲劳断裂、断口尖锐；需多股拧用 |
| 衣架丝（coat hanger） | 应急 | 硬、便宜，但很难弯精细形状 |
| 包胶花艺铁丝 | 细节用 | 软、表面有附着力，适合细缕/呆毛，撑不了大件 |

**线径参考（经验值）：**
- 大马尾 / 大尖角 **主梁**：约 **2mm 或更粗**铝丝；普通铁丝则 1.5~2mm **拧 2~3 股**。
- 中型结构 / 肋骨：约 1~1.5mm。
- 细缕、呆毛、antenna：约 0.5~1mm 包胶花艺丝。
- 原则：**单根撑不住就拧成股或并排**，根部用最粗。

### 1.2 包裹 / 填充
| 材料 | 角色 | 规格建议 |
|---|---|---|
| **化纤毛毡 / 针刺不织布（硬挺 felt）** | 骨架外壳 + 发丝附着面 | **2mm 主力**；1mm 包细节，3mm 做能自立的片状件；选"硬毛毡/高密度" |
| 针刺棉 / 铺棉（蓬松 batting） | 撑体积的填充层 | 蓬松厚度 1cm / 2cm / 3cm，按需 |
| EVA / craft foam 泡棉 | 超大件的轻量骨架/芯 | 2~5mm，常与铁丝混用 |
| 硬衬网 buckram / 定型纱 | 根部锚定底座 | 用于"夹心"固定铁丝端到底网 |

> ⚠️ **不织布选购避坑**：电商标题常把"针棉（蓬松软）/针刺不织布/化纤毛毡（硬挺）/无纺布（很薄）"堆在一起。做**包裹层要硬挺的化纤毛毡**，不是蓬松针棉；很薄的购物袋式无纺布不能用。
> 颜色：发色深就用黑/深灰毛毡，发色浅用白/米，避免发丝稀疏处透色。

### 1.3 头发材料
- **发帘（weft）**：一条条缝好的发排，与主假发**同色**（Arda、Epic Cosplay 等有配色发帘卖；也可买两顶同款拆一顶补量）。
- 散高温丝：表面修饰、补缝、做尖刺。

### 1.4 粘合 / 定型
| 用途 | 推荐 |
|---|---|
| 主力粘合（包布、粘发帘） | **高温热熔胶枪 + 胶棒** |
| 重型锚定（铁丝→底网） | Fabri-Tac / E6000 等工业级强力胶 |
| 柔性收尖、发丝塑形 | Aleene's Original Tacky Glue（透明、干后柔韧、遇水可复活） |
| 强力定型喷雾 | **Got2b Glued Blasting Freeze Spray**（社区标杆）/ 高定型发胶（AquaNet 等） |
| 尖端收锋 | Got2b Glued 发胶（少量点尖端） |

> ❌ 不要用普通发胶（hair gel）涂假发，会黏腻结块。

### 1.5 工具
- **尖嘴钳 + 斜口钳（剪丝）+ 圆嘴钳（弯圈收端）**
- 假发剪、**打薄剪（thinning shears）**
- **倒梳（teasing brush）/ 尖尾梳**
- 假发头模 + T 针（固定假发施工）
- 吹风机 + 热风枪（定型 / 收缩铺棉，热风枪用于发丝须低温慎用）
- 针 + 线（同色，缝发帘、缝锚定）
- 子母扣 / 魔术贴 / 假发夹（toupee/alligator clips）/ 鳄鱼夹——用于分体与戴稳

### 1.6 假发底帽（cap）选择
- **Wefted cap（发帘网帽）**：最常见、便宜、弹性网底，适合一般造型。
- **Hard-front cap（硬前网帽）**：前缘硬挺，能给大型铁丝/泡棉骨架提供**牢固锚点**——做大反重力造型优先考虑硬底/硬锚点区域。

## 2. 金属丝：弯折与配置（精细）

### 2.1 结构原理
把每个反重力部件想成 **"中轴 + 肋骨 + 根部底座"**：
- **主梁（中轴 / spine）**：决定部件的走向与上扬角度，从根延伸到尖。
- **肋骨（ribs）**：沿主梁横向伸出的短丝，把横截面"撑开"成立体形（水滴/弯月/锥），否则部件是扁的。
- **根部底座（base）**：把主梁在根部弯成贴合头型的大圈/底板，**扩大受力面**、分散弯矩。

> 力学直觉：部件越长、越外伸，根部承受的**弯矩 = 重量 × 力臂**越大。所以——越靠根部丝越粗/越多股；力臂能短则短。

### 2.2 弯折手法
1. **先在纸上画 1:1 草图**，标出根部位置、上扬角度、长度、最粗处。
2. 用斜口钳剪丝；用手 + 尖嘴钳**大弧度顺势弯**，避免在同一点反复来回折（金属疲劳→断裂）。
3. 需要急转角时，用尖嘴钳夹住定点弯，弧度尽量留圆，不要折成死角（死角是断裂起点）。
4. **端头处理（必做）**：用圆嘴钳把每个端头**卷成小圆圈**，或套热缩管 / 缠胶带 / 包一小片热塑（Worbla），既防扎人又增大与胶/布的粘合面。
5. 多股配置：主梁用 2~3 根丝**麻花拧紧**成一股；或保留并排再整体包布。根部把多股汇聚后一起接入底座。

### 2.3 根部底座与锚定（buckram 夹心法）
这是反重力假发**最关键工艺**，务必做扎实：
1. 主梁在根部继续延伸，弯成一个**巴掌大、贴合头型的圈或平板**。
2. 把这个底座放在一片硬衬网（buckram）上，铁丝端用强力胶（E6000/Fabri-Tac）粘住。
3. 再盖一片 buckram，**把铁丝端夹在两层网之间** + 胶。
4. 用**双股线沿轮廓缝死**（缝合 + 胶 = 牢固）。
5. 这个加固底座再固定到假发上（缝/粘到底网，或装子母扣做分体——见 §6）。

### 2.4 对称
成对部件：先弯好一侧→照着它（或纸样）弯另一侧→把两件并排比对长度、角度、弧形是否一致，再上布。

## 3. 不织布：选择、配置与安装（精细）

### 3.1 选哪种
- 包裹骨架 / 给发丝附着 → **硬挺化纤毛毡（针刺不织布）2mm**。
- 要饱满体积 → 骨架上先垫**针刺棉/铺棉**再包毛毡外壳。
- 颜色配发色（见 §1.2 避坑）。

### 3.2 三种安装法
**A. 绷带缠绕法**（适合主梁、细处）
- 毛毡裁成条，像绷带螺旋缠绕铁丝，**边缠边点热熔胶**固定。

**B. 夹心外壳法**（适合大马尾、大件，推荐）
1. 骨架平放在一块毛毡上，沿轮廓外留 **1~2cm 缝份**剪出形状。
2. 再剪一片同样形状盖上。
3. 上下两片**把骨架夹住**，沿边缘热熔胶粘合 → 一次成型出立体外壳。

**C. 填充 + 外壳**（要蓬松体积）
- 先在骨架缠/垫针刺棉（可用热风枪轻收缩定型），再用 B 法包毛毡外壳。

### 3.3 粘合要点
- 主力用**热熔胶**；用胶枪金属头把布/发帘压实，避免胶溢到表面。
- **根部受力处：胶 + 缝并用**（毛毡可下针），双保险。
- 聚酯毛毡热熔胶很好粘；用热风枪时离远点、别烧焦（聚酯遇高温会熔缩）。

## 4. 假发本体处理（剪 / 贴 / 缝 / 倒梳）

### 4.1 底网准备 & 戴稳（先解决后坠）
大造型整顶会**后坠/滑脱**，处理顺序：
- 假发内侧**缝入假发夹（toupee/鳄鱼夹）**于额角、后颈、头顶等锚点。
- 配**渔网发网**，让夹子能穿过网咬住自己的头发。
- 自己头发**编一条贴头辫子/盘卷**做锚点，夹子/爪夹咬住辫子最稳。
- 必要时加下巴带 / 多缝几个夹子。

### 4.2 加发量：缝入发帘（wefting）
当造型处发量不够（尤其要做尖刺/大马尾的区域）：
1. 把发帘剪成易操作的小段。
2. 分开假发，露出原有发帘行与底网。
3. 用**同色线**在原有发帘行**之间**缝入新发帘；让新发帘**与原有发帘朝同方向倒伏**，更自然。
4. 从下往上一行行加；急用可热熔胶/Fabri-Tac 代替缝（注意：已上胶的发帘很难再下针，要缝的先缝再上胶）。

### 4.3 桩法（stub / stump）——做反重力马尾的锚点 ★关键
处理"假发本体是否要剪贴"的核心技法，典型如 Sailor Moon 高马尾：
1. 在要长马尾的位置，把假发**原生头发拢成一束马尾**。
2. **贴根剪短**留一小截。
3. 用热熔胶/强力胶把这截**封成一个硬桩（stub）**。
4. 之后把发帘/做好的马尾骨架**螺旋缠绕、热熔胶粘到这个桩上**，构建饱满且牢固的反重力马尾。
> 即：**该剪就剪**——剪短封桩是为了得到一个不晃、能承重的根。这一步通常被外层头发完全盖住，不影响外观。

### 4.4 倒梳（teasing / backcomb）——给体积与持久
- 发帘给"密度"，**倒梳给"持久的蓬起"**（不会到中午就塌）。
- 手法：分出一缕，用尖尾梳/倒梳从发梢向发根方向逆刮，在根部刮出一个"棉垫"。
- 倒梳后喷强力定型喷雾（Got2b Glued Freeze）锁住；表层留一层顺滑头发盖住倒梳的毛糙。
- 可逆：倒梳出错可从梢向根轻梳还原。

### 4.5 发帘螺旋包覆骨架（做整束马尾/大缕）
1. 选同色发帘，从**根部起**沿不织布外壳螺旋缠绕。
2. 发帘布边用热熔胶/假发胶粘到毛毡上，**一圈压一圈往尖端走**。
3. 每圈让上层头发自然垂下盖住下层接缝（瓦片叠压），藏住布与缝。
4. 发丝顺造型/重力方向铺，超出骨架部分自然成尖。
5. 根部第一圈**胶 + 缝**固定。

### 4.6 定型固化
- 整体喷强力定型喷雾，配吹风机/热风枪**边吹边定**弧度。
- 逐层叠加：铺一层发 → 喷 → 吹干 → 再下一层，防下垂位移。
- 尖端用少量 Got2b 发胶捏锋收尖。

### 4.7 是否需要剪 / 怎么剪
- **需要剪的情形**：做承重桩（§4.3）、修飞毛与杂乱发梢、调整刘海/层次、让尖刺收锋。
- **怎么剪不露痕**：用**点剪（point cutting，斜着小口剪）**和**打薄剪**，不要一刀平剪（平剪留生硬钝口）。
- 先少剪、戴上头模反复比对，宁可分次修。

## 5. 常见反重力发型实施步骤

### 5.1 背后大马尾 / 双大马尾（典型反重力）
1. **骨架**：每条做"主梁（2~3 股粗铝丝弯出上扬弧）+ 肋骨（撑出立体截面）+ 根部底座（贴头大圈）"；成对先做纸样保证对称。端头全部收圈。
2. **锚定**：根部底座用 buckram 夹心 + 缝固（§2.3）；在假发对应位置做承重桩（§4.3）或直接缝/扣底座；建议做**分体可拆**（子母扣/魔术贴）便于运输。
3. **包布**：夹心外壳法包 2mm 毛毡；要饱满则先垫针刺棉。
4. **上发**：发帘从根部螺旋包覆到尖（§4.5）；根部胶+缝。
5. **定型**：喷定型 + 吹风定弧；收尖。
6. **戴稳**：内侧假发夹 + 编辫锚点防后坠。

### 5.2 尖刺头（Cloud / 悟空型）
- 小/中尖刺可**纯发丝**：在尖刺区先加发帘 + 根部倒梳 → 分股 → 全段喷 Freeze Spray / 抹 Tacky Glue → 手捏成尖 → 吹风机低温烘干 → 尖端点 Got2b 收锋。
- 大尖刺需**内骨架**：felt/泡棉/铁丝做支撑，发丝包覆 + 倒梳遮缝。

### 5.3 立起的呆毛 / 单股反重力发缕（antenna）
- 细造型用 felt+细丝 或 craft foam+丝 做内芯（felt 纹理利于发胶粘）。
- 把内芯**夹进假发的发丝中间**，用假发胶/发胶上下夹粘定型。

### 5.4 钻头卷 / 螺旋卷（drill）
- 国内常用法："高温丝 + 胶水 + 铁丝定型"。
- 铁丝弯成螺旋芯 → 发丝顺螺旋缠 → 发胶+热定型；钻头根部接桩固定。

### 5.5 大背头 / 向后高掠
- 整片倒梳起底 + 发帘加量 + 发胶定型；超大体积在底层加 felt/泡棉垫片撑形。

### 5.6 大丸子头 / 发髻
- 泡棉球/铺棉团做芯（轻）→ 短铁丝桩接到头顶/后脑锚点 → 发帘螺旋包覆 → 定型。

### 5.7 细长马尾（飘逸尾 / 反重力细尾）
细长马尾分两种做法，先确定它是**反重力上扬/横伸定型**还是**自然垂坠飘逸**——两者结构完全不同：

**A. 自然垂坠的细长马尾（顺重力，最简单）**
- 几乎不用骨架：发帘做成一束，根部接桩/锚定（§4.3），自然垂下。
- 想要轻微弧度或防贴背，穿一根**很细的软丝（包胶花艺丝 0.5~1mm）**做微调，能摆又有形。
- 重点是"细"：发量宜少，尖端让发丝自然出锋收细。

**B. 反重力上扬 / 横伸的细长马尾（最难）**
- 所有造型里**最容易塌**：又细、又长、又要抗重力 → 力臂与弯矩极大，但截面小放不下粗骨架，互相矛盾。
- 骨架：单根**根部粗、向尖端渐细**的铝丝主梁（根部并 2 股 → 中段 1 股 → 尖端去丝只留发），兼顾刚度与轻量；基本不用肋骨。
- **极致减重**：尖端任何多余重量都被力臂放大；发量、填充、胶都要省。可接受尖端略下垂——细长尾尖自然下坠反而灵动。
- 根部照常 buckram 夹心加固（§2.3），细长尤其依赖根部刚性。
- 包布：绷带缠绕法薄包 1~2mm 毛毡，只在有丝段包，尖端纯发。
- 上发：发帘**薄薄螺旋包覆**，发量少保持"细"；发胶定弧，别堆料。

> 与大马尾搭配：细长马尾常作点缀/对比的一缕，位置与锚点要**避开大马尾底座**，单独做成分体更好拆装。

## 6. 重量、平衡与佩戴稳定

- **减重**：优先铝丝、空心结构、少填充；体积靠倒梳和外形而非堆料。
- **重心**：部件尽量贴近头部，别过度外伸；力臂越短越稳。
- **锚定**：内侧多点假发夹 + 渔网发网 + 自己头发编辫；后坠重时下巴带。
- **分体可拆**：大部件根部装子母扣/魔术贴/挂钩，对接到假发上的对应件——运输不压坏、佩戴更稳、收纳方便（强烈推荐用于大马尾/大尖角）。
  - 经验做法：墙挂钩戳孔→细丝"缝"进底网→马尾做成"填充管+内置铝丝+发帘"，挂钩对接。

## 7. 常见问题排查

| 症状 | 原因 | 对策 |
|---|---|---|
| 造型塌陷下垂 | 骨架太细/单根、根部弯矩过大 | 主梁拧股或加粗、缩短力臂、根部加固 |
| 整顶往后滑脱 | 重心后坠、锚定不足 | 加假发夹/编辫锚点/下巴带、减重 |
| 铁丝戳出 / 扎头皮 | 端头未收圈、布太薄 | 端头收圈+包热缩管、外壳加厚 |
| 发丝露出底布 | 发帘没瓦片叠压、颜色不配 | 重叠上层盖缝、毛毡换配发色 |
| 定型不持久、变软 | 仅用胶、没倒梳/喷量不足 | 倒梳打底 + 强力 Freeze Spray 逐层锁定 |
| 运输后压坏 | 整体硬连不可拆 | 改分体可拆 + 专用支撑盒运输 |

## 8. 安全与注意事项

- **玻纤刺激**：若用到玻璃纤维网格带/材料，裁切碎屑刺激皮肤呼吸道，且毛刺扎头皮——务必**不直接接触头皮**，操作戴手套。
- **金属疲劳**：铁丝反复弯折会断且断口尖锐；少来回折、端头收圈。
- **热风枪**：会熔缩聚酯毛毡/烫坏高温丝——离远、低温、慎用于发丝。
- **Got2b / 强力胶清洗**：普通洗发水洗不掉 Got2b Glue，需油性清洁剂；做造型前在隐蔽处试色（有些胶干后会染色/变深）。
- **试做小样**：正式做大件前，先用同材料做个小样验证胶的粘性与定型效果。
